Layout Options

Four different approaches to showing the counter + events + images. These existed as separate HTML files.

Option A

Filmstrip Events
Events shown as a horizontal filmstrip. Each event has an image + title. User scrolls through them horizontally while the counter stays fixed at top. Simple, cinematic.

Option B

HUD + Expandable
Compact heads-up display at top showing just the counter and year. Events expand as a full-screen list below. Each event has an icon, title, and description. Dense and information-rich.

Option D

"The Last Herd"
Most elaborated option. Cards in a responsive grid that illuminate as the timeline reaches their year. Each card has an image, year badge, title, description, and source. Deterministic schedule maps time to year. This was iterated 8 times (v1 through v8 current).

Scroll-Driven Mode

Separate approach — user scrolls through event cards, counter interpolates based on scroll position. No play button, user controls the pace entirely.

Scroll Prototype

User-controlled pace

Instead of auto-playing, the user scrolls through cards. The counter interpolates the population for each card's scroll position. Cards dim when not at focal point, illuminate when scrolled into view. Snap-scroll makes each card land cleanly.
